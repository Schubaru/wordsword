# Haikuzy: one haiku a day, one word hidden in it. Read by `HaikuzyBank`.
#
#   season | line one / line two / line three
#
# The hidden word sits in {braces}: it's the word the poem turns on, uncommon but known.
# `{cardinal:bird+bird,redbird,robin,songbird,finch,sparrow,jay}` names the sense the poem means, for the related-words lookup only — the word
# to guess is still just "cardinal".
# Seasons are northern meteorological ones: winter Dec–Feb, spring Mar–May, summer Jun–Aug,
# autumn Sep–Nov. A day shows the next haiku of its own season, in file order, so keep each
# season's haiku in the order they should be read and APPEND new ones at the end of a season's
# run only — inserting reshuffles every future day of that season.
#
# Rules, enforced by `HaikuzyBank.selfCheck()` on every DEBUG launch:
#   - exactly one {word}, lowercase letters only, and it's in haiku-words.txt
#   - no other word in the poem is the hidden word or shares its root
#   - the hidden word has a `haikuzy-near.txt` line (run Scripts/make-haikuzy-near.swift after
#     adding haiku)
#   - no hidden word twice in the bank
#
# Craft: one moment, present tense, two images set against each other across a cut (the dash).
# The season is in the images, never named as a feeling. No rhyme, no title. Lines run
# short-long-short, about 10–17 syllables; 5-7-5 is common, not required.
